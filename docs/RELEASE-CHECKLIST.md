# ONLYTOOLS Release Checklist

## Version and source
- [ ] User-visible changes reviewed.
- [ ] SemVer bump and rationale recorded.
- [ ] Product version, tag, title, and package version agree.
- [ ] CHANGELOG updated.

## Documentation
- [ ] README matches actual product.
- [ ] Windows requirements and architecture verified.
- [ ] Install/upgrade/uninstall instructions checked.
- [ ] Release Notes complete; screenshots current.
- [ ] Legacy-name history preserved where applicable.

## Build and distribution
- [ ] Windows build and tests actually completed.
- [ ] Installer/portable package smoke-tested.
- [ ] Upgrade/data migration tested if relevant.
- [ ] Asset names, sizes, architectures checked.
- [ ] SHA-256 calculated from final assets.
- [ ] GitHub and mirror downloads tested.

## Authorization
- [ ] Human owner explicitly approved public publication.
